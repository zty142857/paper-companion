# 阅读界面原位翻译决策记录

## 已确定

### 固定 PDF 版式，译文排版近似
- **结论**：保持页数、缩放和原文块位置不变，通过遮住原文并叠加译文实现原位替换；译文默认自动缩小字号，仍溢出时提供完整译文浮层，不做 HTML 全文重排。
- **理由**：能保留现有页码定位、卡片锚点和 PDF 坐标体系，避免重做整套阅读交互；现有解析数据不足以逐字复刻字体、粗斜体和行距。

### 首版只处理普通段落和标题
- **结论**：首版原位替换普通段落与标题，保留公式和图片位图，跳过表格、表内文字和参考文献；不翻译公式区域。
- **理由**：普通文本最符合连续阅读需求；当前公式缺少 LaTeX、表格缺少单元格坐标，纳入首版会显著增加复杂度和损坏内容的风险。

### 原位翻译替代旧翻译卡片
- **结论**：以原位翻译替代旧的整段翻译卡片；隐藏旧的整段翻译卡但保留数据库记录，其他类型卡片不变。划词翻译弹窗、划词译文卡和手动存卡继续保留，新原位翻译不再自动生成卡片。
- **理由**：避免重复展示和挤占轨道，同时不破坏已有数据；划词翻译处理局部片段，与整段原位阅读的用途不同，完全隐藏会让“存为卡片”失去意义。
### 同时支持逐段与按章节原位替换
- **结论**：保留原有排版和阅读位置，支持单段原文/译文替换，也支持按已有章节批量翻译并替换，不做一键全文翻译。
- **理由**：逐段替换适合局部阅读，按章节批量替换能利用现有章节划分，同时控制全文翻译的耗时、费用和失败影响范围。

### 译文溢出采用缩字加展开
- **结论**：译文默认在原块范围内自适应缩小字号，设置最小可读字号；仍放不下时提供展开完整译文的入口，不覆盖后续正文或图表。
- **理由**：固定版式下完全保持原字号容易溢出，框内滚动会频繁打断连续阅读，向下覆盖又会损坏未翻内容。

### 支持全局和单段原文/译文切换
- **结论**：提供全局“原文/译文”开关控制所有已翻译内容，单个已翻译块也可临时查看原文；未翻译内容始终显示原文。
- **理由**：全局切换适合连续阅读，单段切换方便局部校对，且不会把未翻译块显示为空白。

### 章节翻译采用顺序渐进执行
- **结论**：章节内按原段落顺序逐段请求，完成一段立即显示一段；支持停止，失败段保留原文并可单独重试。
- **理由**：相比并发或整章合并请求，顺序执行更稳定，限流、取消、失败隔离和成本控制更简单，也避免模型漏段后难以对齐。

### 译文模式以连续阅读优先
- **结论**：译文模式支持选中和复制译文；原文标亮与原文检索高亮暂不显示，公式和表格工具继续可用，相关原文工具可切回原文模式使用。
- **理由**：现有标亮和检索依赖原文字形坐标，直接叠加到译文上会错位；首版不应为保留错位功能损害阅读体验。

### 章节范围包含子章节
- **结论**：点击章节翻译时，包含当前章节及其下级章节，到同级或更高一级标题为止；第一章之前的内容作为“开篇”单独提供翻译入口。
- **理由**：符合按章节连续阅读的预期，也利用现有标题层级；开篇内容仍可阅读和翻译，不因没有正式章节标题而遗漏。

### 跨页段落按物理块翻译
- **结论**：跨页逻辑段落拆成两个物理块分别请求和缓存；完整逻辑段落只作为理解上下文的材料，模型只输出当前物理块的译文。
- **理由**：原位显示必须贴合每一页的原文块，分别翻译可避免整段译文在两页重复；同时保留整段上下文，减少指代和句意被页边界切断的问题。

### 行内公式随段落照常翻译
- **结论**：独立公式继续保留 PDF 原图；普通段落中的行内公式随段落翻译，要求模型保留数学符号，并通过现有 Markdown/KaTeX 渲染。
- **理由**：行内公式难以从当前块文本中可靠拆出，跳过会让大量正常段落无法使用原位翻译；保留符号并由 KaTeX 渲染可兼顾可读性与内容完整性。

### 译文永久复用并支持手动重译
- **结论**：以 `paper_id + block_id` 永久缓存译文；已有译文默认复用，不因更换模型、修改提示词或解析文本变化自动失效。单段和整章都提供手动“重新翻译”。
- **理由**：符合用户对稳定阅读和成本控制的要求，避免切换模型后意外产生大量请求；需要更新译文时由用户明确触发。

### 旧卡片处理补充
- **结论**：旧整段翻译卡只隐藏、不迁移、不删除；带 `selection` 标记的划词卡保留展示。新原位译文不读取旧卡片中的截断原文作为缓存依据。
- **理由**：旧卡片可能只保存原文前 160 字，无法可靠校验与物理块的对应关系；保留划词卡则维持手动收藏局部译文的能力。

## 已确认的项目事实

- 阅读页是 PDF canvas 位图加透明文本层，正文不是可重排的 HTML；原位替换需要按块遮住原文并叠加译文，无法直接获得完全一致的字体、粗斜体和行距。
- 当前翻译按逻辑段落逐次调用模型，没有按块缓存或批量任务；已有翻译卡片持久化完整译文，但只保存原文前 160 字。
- 整块公式没有可重排的 LaTeX，表格没有单元格坐标；图片、公式和表格不适合直接套用普通段落的原位覆盖。
- 覆盖译文会影响现有选中、标亮、检索、表格和公式交互，需要明确原文/译文模式及各模式行为。

## 首版实现

- 阅读页顶栏提供全局“原文/译文”切换；单段工具条提供翻译、重新翻译和查看原文/译文。
- 段落工具条在点击翻译、重新翻译、切换原文/译文或提问后立即关闭，不再停在页面上。
- 章节批量翻译入口改为在章节导航条目上右键打开菜单，避免常驻按钮挤占目录。
- 正文译文统一使用全书正文基准字号；允许在不遮挡下一块的前提下向下扩展约两行，仍溢出时只显示完整行，并在最后一行末尾显示小三角用于展开。
- 页脚、资助信息、版权行等底部小字从正文块中分离且不参与翻译；旧论文重算跨页链接时会忽略正文末尾残留的页脚文字。
- 章节目录按章节翻译，包含有编号章节的下级标题；有编号章节范围内的无编号小标题视为子标题。无编号一级标题因层级不可靠，只翻译自身小节；第一章之前的内容归入“开篇”。
- 章节翻译支持进度显示、停止和失败重试。停止、离开论文或切换论文会中止后续请求；失败不会覆盖此前已有的有效译文。
- PDF 页内按原文块坐标覆盖译文，自动缩字到可读下限，溢出时提供完整译文浮层。
- 译文模式的原文标亮和检索高亮隐藏；公式框选、表格操作和译文复制可用。
- 后端新增 `GET /api/papers/{pid}/translations` 与 `POST /api/papers/{pid}/translate-inline`，翻译继续走 `translate` 模型路由。
- 已通过前端构建与 lint、后端原位翻译/跨页/划词/公式/表格/模型设置测试，并在真实 PDF 阅读页验证单段替换、全局切换、章节批量进度和长译文展开。

## 待定
